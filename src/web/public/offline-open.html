Open a sealed letter offline

This page opens a letter from a sealed export and its keepsake. It runs entirely in this browser: it never connects to a server, and it keeps working if the service that made the letter has closed.

Save this page and open the saved copy to use it. A web server's security policy stops its script from running here, by design.

The file the author downloaded with "Export the sealed letters", usually sealed-letters.json.

Paste the keepsake link, or type the code printed on the keepsake card. Letters kept in vault custody need none.
