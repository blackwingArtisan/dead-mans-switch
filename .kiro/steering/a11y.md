# Accessible gothic

Loaded when any web file is in play. The costume never costs anyone the content.

- **Contrast:** every text colour meets WCAG AA (4.5:1, or 3:1 for large text) against its real background, including the dimmed room states (`body[data-room]`) and placeholders.
- **Text beside every picture:** the candle, seals and room are decorative and `aria-hidden`. Each state, deadline and count is also written in text next to them.
- **Announcements:** state changes go to a polite live region (`role="status"`), including the room line from `lib/room.ts`.
- **Motion:** every animation (flicker, embers, smoke, relight, seal crack, candlelight reveal, ink signature) has a `prefers-reduced-motion` path that shows the end state at once. The candlelight reveal must open fully lit under reduced motion, and "Light the room" must always be available.
- **Keyboard:** everything works without a pointer, with a visible ember focus ring and the skip link first in tab order. Dialog-like panels close on Escape and return focus.
- **Forms:** use `noValidate` with in-theme errors from `lib/validate.ts`: a message under the field, `aria-invalid`, `aria-describedby`, focus on the first invalid field.
- **Layout:** no horizontal scroll at 360 px; the check-in is above the fold at 390 px.
- **Proof:** the axe audit in `tests/e2e/a11y.spec.ts` must stay at zero WCAG 2.2 AA violations; add a page or state to it when you add one.
